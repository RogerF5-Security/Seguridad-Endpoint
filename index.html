Autor:
Roger Arana

EDR / XDR Blue Team Technical Reference
RESUMEN TÉCNICO: Este documento define las capacidades, limitaciones y casos de uso de las tecnologías de protección de endpoint, diferenciando claramente entre prevención basada en firmas (AV), prevención avanzada (EPP), detección post-ejecución (EDR) y correlación extendida (XDR).
1. Antivirus Tradicional (AV) Legado
Definición Técnica

Software de seguridad diseñado para prevenir, detectar y eliminar malware basándose principalmente en coincidencias de firmas estáticas. Funciona comparando el contenido de los archivos escaneados contra una base de datos local o en la nube de amenazas conocidas.

Mecanismo de Funcionamiento
  • Firmas Hash: Comparación de MD5/SHA256 del archivo completo.
  • Firmas de Cadena (Bytes): Búsqueda de secuencias hexadecimales específicas dentro del binario.
  • Heurística Básica: Detección de patrones simples (ej. un ejecutable comprimido con UPX).
Limitaciones Críticas
  • Ineficaz contra ataques Fileless (solo en memoria).
  • Ceguera ante malware polimórfico (código que cambia en cada ejecución).
  • Cero visibilidad sobre lo que hace el malware una vez ejecutado.
Ejemplos Comerciales / Históricos:
Symantec Endpoint Protection (Legacy), McAfee VirusScan Enterprise, ClamAV (Open Source), Windows Defender (Versiones pre-Windows 10).
2. Endpoint Protection Platform (EPP) Estándar Mínimo
Definición Técnica

Solución integrada que evoluciona el AV tradicional incorporando múltiples tecnologías de prevención pre-ejecución. Su objetivo principal es bloquear la amenaza antes de que se escriba en disco o se inicie el proceso, reduciendo la superficie de ataque del endpoint.

Capacidades Adicionales
  • Machine Learning (ML) Estático: Análisis de características del archivo (sin firmas) para predecir maliciosidad.
  • Control de Dispositivos: Gestión de puertos USB y periféricos.
  • Host Firewall / IPS: Filtrado de tráfico de red a nivel de host.
  • Control de Aplicaciones: Listas blancas/negras de software permitido.
Limitaciones Críticas
  • Falsos positivos generados por modelos de ML agresivos.
  • Limitada capacidad para detener ataques que usan herramientas nativas del sistema (Living off the Land Binaries - LOLBins) como PowerShell o WMI.
Ejemplos Comerciales:
Trend Micro Apex One, Sophos Intercept X (Versiones Base), Kaspersky Endpoint Security, Trellix (McAfee) EPP, ESET Endpoint Security.
3. Endpoint Detection & Response (EDR) Avanzado
Definición Técnica

Tecnología centrada en la visibilidad post-ejecución y la respuesta a incidentes. El EDR asume que la prevención fallará y se dedica a monitorear, grabar y analizar el comportamiento del endpoint en tiempo real para detectar actividades anómalas que un EPP no bloquearía.

Mecanismo de Funcionamiento
  • Telemetría Continua: Recolección de eventos de procesos, registro, red y archivos (vía Kernel Callbacks o ETW).
  • Threat Hunting: Capacidad para buscar Indicadores de Compromiso (IoCs) en todo el parque histórico.
  • Respuesta Remota: Aislamiento de red del host, eliminación de procesos y apertura de Shell remota para forense.
Diferenciador Clave

Detecta técnicas de ataque, no solo archivos. Ejemplo: Un EDR detectará un script de PowerShell inyectando código en lsass.exe (Credential Dumping), mientras que un AV/EPP podría verlo como un proceso legítimo.

Ejemplos Comerciales Líderes:
CrowdStrike Falcon Insight, SentinelOne Singularity, Microsoft Defender for Endpoint (Plan 2), Carbon Black EDR, Cybereason.
4. Extended Detection & Response (XDR) Holístico
Definición Técnica

Evolución del EDR que rompe los silos de información. El XDR es una plataforma que unifica, ingesta y correlaciona datos de múltiples vectores de seguridad (no solo del endpoint) para proporcionar una detección integrada y una respuesta orquestada.

Vectores Integrados
  • Endpoint: Datos de EDR.
  • Red (NDR): Logs de Firewall y análisis de tráfico.
  • Identidad: Logs de Active Directory / Azure AD.
  • Cloud: Cargas de trabajo en AWS/Azure/GCP.
  • Email: Datos de gateways de correo seguro.
Valor Estratégico

Reduce la fatiga de alertas mediante IA. En lugar de generar 50 alertas separadas (1 del firewall, 1 del antivirus, 48 del EDR), el XDR correlaciona los eventos y presenta un solo incidente con la cadena de ataque completa.

Ejemplos Comerciales:
Palo Alto Networks Cortex XDR, Trend Micro Vision One, Microsoft 365 Defender (XDR nativo), Fortinet FortiXDR, Trellix XDR.
